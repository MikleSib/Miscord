# Система шумоподавления Miscord

## Текущая ситуация

После анализа и тестирования выяснилось, что **дополнительная процессорная обработка аудио не работает с WebRTC**. WebRTC peer connections используют оригинальные медиа треки и применяют свои собственные алгоритмы шумоподавления.

## Что было сделано

### ✅ Улучшения браузерного шумоподавления
- Добавлены агрессивные настройки в `getUserMedia()`:
  - `googEchoCancellation: true`
  - `googNoiseSuppression: true`
  - `googAutoGainControl: true`
  - `googHighpassFilter: true`

### ❌ Проблема с дополнительной обработкой
Созданная система процессорного шумодава (`advancedNoiseGate.ts`) работает локально, но **не влияет на передаваемый аудиопоток в WebRTC**.

## Рекомендации

### Для пользователей:
1. **Используйте встроенные настройки браузера** - они обеспечивают лучшее качество
2. **Не полагайтесь на дополнительную обработку** - она может не работать
3. **Настройте микрофон в системе** для оптимального качества

### Для разработчиков:
1. **Фокусируйтесь на браузерных алгоритмах** шумоподавления
2. **Используйте WebRTC встроенные возможности**
3. **Дополнительная обработка может потребоваться только для локальной обработки**

## Тестирование

### Как проверить шумоподавление:
1. Войдите в голосовой канал
2. Говорите в микрофон
3. Другие пользователи должны слышать чистый голос без шумов

### Если шумодав не работает:
1. Проверьте настройки браузера (Chrome/Firefox)
2. Убедитесь, что микрофон не имеет аппаратных проблем
3. Попробуйте другой браузер

## Технические детали

### WebRTC ограничения:
- `RTCPeerConnection.addTrack()` использует оригинальные медиа треки
- Браузер применяет шумоподавление на уровне WebRTC engine
- Дополнительная обработка через Web Audio API не влияет на передачу

### Рекомендуемые настройки:
```javascript
const constraints = {
  audio: {
    echoCancellation: true,
    noiseSuppression: true,
    autoGainControl: true,
    googEchoCancellation: true,
    googNoiseSuppression: true,
    googAutoGainControl: true,
    googHighpassFilter: true,
  }
};
```

## Заключение

**Браузерные алгоритмы шумоподавления в современных браузерах (Chrome, Firefox, Safari) достаточно эффективны** и обеспечивают хорошее качество звука. Дополнительная обработка может потребоваться только для специфических случаев локальной обработки аудио.
