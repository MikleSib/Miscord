# Звуки голосового канала

## Описание
Добавлена система воспроизведения звуков при подключении и отключении пользователей к голосовому каналу.

## Файлы звуков
- `/frontend/public/music/звук подключения к звонку.mp3` - звук при подключении
- `/frontend/public/music/звук отключения от звонка.mp3` - звук при отключении

## Реализация

### 1. SoundService (`frontend/src/services/soundService.ts`)
Сервис для управления воспроизведением звуков:
- `playJoinSound()` - воспроизводит звук подключения
- `playLeaveSound()` - воспроизводит звук отключения
- `setVolume(volume)` - устанавливает громкость (0-1)
- `isReady()` - проверяет готовность сервиса

### 2. Интеграция в VoiceService (`frontend/src/services/voiceService.ts`)
Звуки воспроизводятся при получении событий:
- `user_joined_voice` - звук подключения
- `user_left_voice` - звук отключения

### 3. Интеграция в Store (`frontend/src/lib/store.ts`)
Звуки воспроизводятся при глобальных событиях:
- `voice_channel_join` - звук подключения
- `voice_channel_leave` - звук отключения

### 4. Интеграция в VoiceSlice (`frontend/src/store/slices/voiceSlice.ts`)
Звуки воспроизводятся при собственных действиях пользователя:
- При подключении к голосовому каналу
- При отключении от голосового канала

## Тестирование
Добавлен компонент `SoundTest` для тестирования звуков:
- Кнопки для воспроизведения звуков
- Настройка громкости
- Индикатор готовности сервиса

## Использование
Звуки воспроизводятся автоматически при:
1. Подключении любого пользователя к голосовому каналу **в том же канале, где находитесь вы**
2. Отключении любого пользователя от голосового канала **в том же канале, где находитесь вы**
3. Собственном подключении/отключении пользователя

## Логика воспроизведения
- **Проверка канала**: звуки воспроизводятся только если событие происходит в том же голосовом канале, где находится пользователь
- **Проверка пользователя**: звуки не воспроизводятся для собственных действий
- **Изоляция**: пользователи в других каналах не слышат звуки событий из чужих каналов

## Настройки
- Громкость по умолчанию: 70%
- Звуки предзагружаются при инициализации
- Обработка ошибок воспроизведения
