# DeepFilterNet Integration Plan

## Обзор

DeepFilterNet - это современная система шумоподавления на основе глубокого обучения, которая превосходит RNNoise и другие традиционные методы.

## Архитектура

### Текущая система
- RNNoise (базовый ML)
- Браузерные фильтры (noiseSuppression, echoCancellation)
- VAD (@ricky0123/vad-web)

### Новая система с DeepFilterNet
- **DeepFilterNet3** - основной движок (ONNX/WASM)
- Браузерные фильтры (как fallback)
- VAD (сохраняется)

## Варианты реализации

### Вариант 1: ONNX Runtime Web (Рекомендуется)
**Преимущества:**
- Работает в браузере
- Хорошая производительность
- Не требует серверной части

**Недостатки:**
- Размер модели ~10MB
- Требует WebAssembly

### Вариант 2: Python Backend
**Преимущества:**
- Максимальная производительность
- Использует оригинальный PyTorch код

**Недостатки:**
- Требует серверную обработку
- Дополнительная задержка сети

### Вариант 3: Rust/WASM (Оптимальный для Electron)
**Преимущества:**
- Нативная производительность
- Минимальная задержка
- Работает локально

**Недостатки:**
- Сложнее в реализации

## Выбранный подход: ONNX Runtime Web + AudioWorklet

### Этапы реализации

1. **Установка зависимостей**
   ```bash
   npm install onnxruntime-web
   ```

2. **Скачивание модели DeepFilterNet3**
   - Модель в формате ONNX
   - Размещение в `public/models/`

3. **Создание DeepFilterNet сервиса**
   - `deepFilterNetProcessor.ts` - AudioWorklet процессор
   - Интеграция с существующей системой

4. **Обновление UI**
   - Переключатель между RNNoise и DeepFilterNet
   - Настройки качества/производительности

## Технические детали

### Требования к аудио
- Sample Rate: 48000 Hz
- Frame Size: 480 samples (10ms)
- Channels: Mono

### Производительность
- CPU: ~5-10% на современном процессоре
- Задержка: ~20-30ms (алгоритмическая + обработка)
- RAM: ~50MB (модель + буферы)

## Совместимость

- ✅ Chrome/Chromium 90+
- ✅ Edge 90+
- ✅ Electron 13+
- ⚠️ Firefox (требует WebAssembly SIMD)
- ❌ Safari (ограниченная поддержка WASM)

## Миграция

1. Сохранить RNNoise как fallback
2. Добавить DeepFilterNet как опцию
3. Автоопределение поддержки
4. Постепенный переход пользователей
