# Интерфейс демонстрации экрана

## Описание
Реализован фирменный интерфейс демонстрации экрана Miscord с переключением между трансляциями, компактным отображением и контролами.

## Компоненты

### 1. ScreenShareViewer (`frontend/src/components/ScreenShareViewer.tsx`)
Основной компонент для отображения демонстрации экрана:
- **Заголовок** с информацией о канале и стримере
- **Основная область** для видео потока
- **Правая панель** с участниками и контролами
- **Кнопки управления**: свернуть, полноэкранный режим, закрыть
- **Свернутое состояние** с мини-индикатором

### 2. ScreenShareButton (`frontend/src/components/ScreenShareButton.tsx`)
Кнопка для управления демонстрацией экрана:
- Переключение между началом/остановкой демонстрации
- Визуальная индикация текущего состояния
- Интеграция с VoiceService

### 3. Интеграция в ChatArea
- Автоматическое отображение при начале демонстрации
- Обработка событий от VoiceService
- Управление состоянием демонстрации

## Функциональность

### ✅ Возможности:
- **Переключение между стримами** - выбор активного демонстратора
- **Компактное отображение** - не на весь экран
- **Контролы управления** - свернуть, полноэкранный режим, закрыть
- **Список участников** - с возможностью переключения
- **Голосовые контролы** - управление микрофоном и настройками
- **Автоматическое скрытие** - при отсутствии активных стримов

### 🎛️ Управление:
- **Кнопка демонстрации** в заголовке чата
- **Переключение стримов** кликом по участнику
- **Свертывание** для продолжения работы в чате
- **Полноэкранный режим** для фокуса на демонстрации

## События

### Обрабатываемые события:
- `screen_share_start` - начало демонстрации
- `screen_share_stop` - остановка демонстрации  
- `open_screen_share` - принудительное открытие

### Интеграция с VoiceService:
- Автоматическое добавление видео элементов
- Управление состоянием демонстрации
- Синхронизация с голосовым каналом

## Дизайн

### Визуальный стиль Miscord:
- Темная тема с серыми оттенками
- **Компактное отображение** - занимает только правую часть экрана (начиная с 320px слева)
- **Левая панель остается видимой** - серверы и каналы всегда доступны
- Индикаторы состояния (красная точка для активного стрима)
- Плавные переходы и hover-эффекты

### Позиционирование:
- **Фиксированное позиционирование**: `fixed top-0 right-0 bottom-0 left-80`
- **Z-index иерархия**:
  - Левые панели (ServerList, ChannelSidebar): z-50
  - Профиль пользователя и голосовые панели: z-50
  - ConnectionStatus: z-50
  - Демонстрация экрана: z-40
- **Свернутое состояние**: позиционируется справа, не перекрывая левую панель

### Адаптивность:
- Полноэкранный режим
- **Свернутое состояние** - полностью скрывает основной контейнер, показывает только мини-индикатор
- Автоматическое скрытие при отсутствии стримов
- **Сохранение доступа к навигации** - левые панели всегда видны
- **Неблокирующее взаимодействие** - в свернутом состоянии чат полностью доступен
