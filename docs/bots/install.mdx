Ссылка установки формируется из настроек приложения и открывает безопасный экран авторизации Miscord.

<Steps>
  <Step title="Настройте разрешения">
    Откройте приложение в [портале разработчика](https://miscord.ru/developers) и перейдите в раздел **Бот**. Отметьте только те разрешения, которые действительно нужны интеграции.
  </Step>
  <Step title="Выберите контексты">
    Для бота, работающего на сервере, включите **Установка на сервер**. Если команды должны быть доступны конкретному пользователю, включите **Установка для пользователя**.
  </Step>
  <Step title="Скопируйте ссылку">
    Нажмите **Копировать ссылку установки** и откройте её в браузере.
  </Step>
  <Step title="Подтвердите доступ">
    Выберите сервер, которым вы можете управлять, либо установку для своего пользователя. Проверьте запрошенные разрешения и подтвердите действие.
  </Step>
</Steps>

## Разрешение «Администратор»

При выборе **Администратор** остальные разрешения становятся недоступны: этот флаг уже включает полный доступ на сервере.

<Warning>
  Не запрашивайте права администратора только ради упрощения настройки. Минимальный набор прав снижает последствия ошибки или утечки токена.
</Warning>

## Рекомендуемый минимум

Для бота, который только читает канал и отвечает сообщениями, обычно достаточно:

- просмотра каналов;
- чтения истории сообщений;
- отправки сообщений;
- использования внешних эмодзи — только если они нужны ответам.

Для управления входящими вебхуками дополнительно требуется разрешение **Управление вебхуками**.
