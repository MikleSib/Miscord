Miscord поддерживает slash-команды, команды пользователя, команды сообщения и primary entry point.

## Создание в портале

<Steps>
  <Step title="Откройте приложение">
    Перейдите в [портал разработчика](https://miscord.ru/developers) и выберите приложение.
  </Step>
  <Step title="Создайте команду">
    В блоке команд укажите тип, имя, описание и ответ. Для серверной команды укажите ID сервера; без него команда будет глобальной.
  </Step>
  <Step title="Настройте доступность">
    Выберите контексты, типы установки, права участников, NSFW и при необходимости локализации.
  </Step>
  <Step title="Добавьте параметры">
    В `Options JSON` можно задать варианты выбора, autocomplete и вложенные подкоманды.
  </Step>
  <Step title="Сохраните и синхронизируйте">
    После сохранения команда появляется в доступных контекстах установленного приложения.
  </Step>
</Steps>

## HTTP endpoint для interactions

В расширенных настройках приложения укажите публичный HTTPS URL. При сохранении Miscord отправит подписанный PING:

```json
{
  "id": "...",
  "application_id": "...",
  "type": 1,
  "token": "endpoint-verification",
  "version": 1
}
```

Endpoint должен вернуть:

```json
{ "type": 1 }
```

Каждый запрос содержит заголовки `X-Signature-Ed25519` и `X-Signature-Timestamp`. Проверяйте подпись до разбора и выполнения payload.

<Card title="Проверка подписи" icon="shield-check" href="/webhooks/security">
  Используйте public key приложения и исходные байты тела запроса.
</Card>
