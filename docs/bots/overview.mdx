Бот — это приложение Miscord с отдельной учётной записью, токеном, разрешениями и командами. Один бот может быть установлен на несколько серверов, а поддерживаемые приложения — ещё и для конкретного пользователя.

## Основные части

<CardGroup cols={2}>
  <Card title="Приложение" icon="box">
    Хранит имя, описание, изображение, public key, OAuth-настройки и команды.
  </Card>
  <Card title="Bot token" icon="key-round">
    Секрет для REST API и Gateway. Передаётся только в заголовке `Authorization: Bot …`.
  </Card>
  <Card title="Установка" icon="user-plus">
    Связывает приложение с сервером или пользователем и фиксирует разрешения.
  </Card>
  <Card title="Доставка событий" icon="radio">
    Gateway передаёт события постоянно, а HTTP endpoints принимают interactions и события приложения.
  </Card>
</CardGroup>

## REST-аутентификация

Каждый запрос бота к API v1 должен содержать заголовок:

```http
Authorization: Bot MISCORD_BOT_TOKEN
```

<Warning>
  Bot token предоставляет полный доступ от имени приложения. Не отправляйте его в браузерный клиент и не записывайте в логи.
</Warning>

## Способы получения событий

<Tabs>
  <Tab title="Gateway">
    Постоянное WebSocket-соединение. Подходит для сообщений, изменений серверов и других событий в реальном времени.
  </Tab>
  <Tab title="Interactions endpoint">
    HTTPS endpoint для команд, компонентов и autocomplete. Miscord подписывает каждый запрос ключом приложения.
  </Tab>
  <Tab title="Event Webhooks">
    HTTPS endpoint для событий жизненного цикла приложения. Получатель подтверждает доставку пустым HTTP `204`.
  </Tab>
</Tabs>
