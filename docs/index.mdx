Miscord предоставляет API v1, Gateway, команды приложений и вебхуки для интеграции ваших сервисов с серверами и пользователями.

<Note>
  Базовый REST URL: `https://miscord.ru/api/v1`. Gateway: `wss://miscord.ru/gateway?v=1&encoding=json`.
</Note>
