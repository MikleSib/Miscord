Для создания вебхука нужны права управления вебхуками в выбранном текстовом канале.

<Steps>
  <Step title="Откройте настройки канала">
    Откройте меню нужного текстового канала и выберите **Настройки канала**.
  </Step>
  <Step title="Перейдите в интеграции">
    В левом меню выберите **Интеграция**, затем раздел **Вебхуки**.
  </Step>
  <Step title="Создайте вебхук">
    Нажмите **Новый вебхук**. Miscord сразу создаст интеграцию и покажет секретный URL.
  </Step>
  <Step title="Сохраните URL">
    Скопируйте URL до закрытия окна. Полное значение показывается только один раз.
  </Step>
  <Step title="Настройте внешний вид">
    Задайте имя, аватар и канал назначения. Здесь же можно отправить тестовое сообщение.
  </Step>
</Steps>

<Warning>
  Не публикуйте URL вебхука в репозитории, логах и скриншотах. Любой, у кого есть URL, сможет отправлять сообщения в канал.
</Warning>

## Если URL потерян

Откройте настройки вебхука и нажмите **Сбросить токен**. Miscord выдаст новый одноразовый URL, а предыдущий перестанет работать.
