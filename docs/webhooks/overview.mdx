В Miscord есть два разных сценария вебхуков.

<CardGroup cols={2}>
  <Card title="Входящий вебхук" icon="message-square-share" href="/webhooks/create">
    Секретный URL принимает HTTP POST и публикует сообщение в выбранном текстовом канале.
  </Card>
  <Card title="Event Webhooks" icon="radio" href="/webhooks/events">
    Miscord отправляет подписанные события приложения на ваш публичный HTTPS endpoint.
  </Card>
</CardGroup>

## Когда использовать

| Задача | Подход |
| --- | --- |
| Отправить уведомление мониторинга в канал | Входящий вебхук |
| Публиковать результаты CI/CD | Входящий вебхук |
| Узнать об установке или удалении приложения | Event Webhooks |
| Обрабатывать slash-команды | Interactions endpoint |
| Получать поток событий сервера | Gateway |

<Warning>
  URL входящего вебхука содержит секретный токен. Public key приложения, напротив, не является секретом и используется получателем для проверки подписи.
</Warning>
