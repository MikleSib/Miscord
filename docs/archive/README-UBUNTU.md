# 🚀 Автоматическое развертывание Miscord на Ubuntu 22.04

## ⚡ Супер-быстрый старт (1 команда)

```bash
# Клонируем проект
git clone <your-repo-url> /opt/miscord && cd /opt/miscord

# Запускаем автоматическую установку
chmod +x quick-start.sh && ./quick-start.sh
```

Выберите пункт **1** для полной автоматической установки!

## 📋 Что происходит автоматически

### 🔧 Установка системы (ubuntu-setup.sh)
- ✅ Обновление Ubuntu 22.04
- ✅ Установка Docker и Docker Compose
- ✅ Настройка брандмауэра UFW
- ✅ Установка Fail2ban для защиты
- ✅ Настройка автообновлений
- ✅ Оптимизация системных лимитов
- ✅ Настройка Docker daemon

### 🐳 Развертывание приложения (auto-deploy.sh)
- ✅ Проверка DNS для stream-cash.ru
- ✅ Создание .env файла
- ✅ Запуск всех контейнеров поэтапно
- ✅ Получение SSL сертификата Let's Encrypt
- ✅ Настройка автообновления сертификатов
- ✅ Проверка доступности всех сервисов

## 🎯 Результат

После выполнения всех скриптов у вас будет:
- 🌐 Работающий сайт на https://stream-cash.ru
- 🔒 Автоматически обновляемый SSL сертификат
- 🛡️ Защищенная система с брандмауэром
- 📊 Мониторинг и логирование
- 🔄 Автоматический перезапуск сервисов

## 🛠️ Управление после установки

```bash
# Проверка статуса
docker-compose ps

# Логи
docker-compose logs -f

# Перезапуск
docker-compose restart

# Остановка
docker-compose down

# Запуск
docker-compose up -d
```

## ⚠️ Важно после установки

1. **Смените SECRET_KEY** в файле `.env`
2. **Проверьте email** в `init-letsencrypt.sh`
3. **Убедитесь в настройке DNS** для stream-cash.ru

## 🆘 Если что-то пошло не так

```bash
# Проверка логов
docker-compose logs -f

# Перезапуск всех сервисов
docker-compose restart

# Полная переустановка
docker-compose down
./auto-deploy.sh
```
