## 🚀 Как протестировать

### 1. Перезапустить бэкенд

**С Docker:**
```bash
docker-compose restart backend
```

**Или локально:**
```bash
# Перезапустить Python процесс бэкенда
cd backend
python main.py
```

### 2. Проверить функциональность

1. Откройте два браузера (или две вкладки в режиме инкогнито)
2. Войдите под разными аккаунтами
3. На первом аккаунте зайдите в голосовой канал
4. На втором аккаунте должно появиться:
   - Уведомление о присоединении пользователя
   - Аватарка участника в списке голосового канала
   - Звук присоединения (если включены звуки)

### 3. Проверить логи

**Backend логи должны показать:**
```
[UnifiedWS] 🎤 username присоединился к голосовому каналу 123
[WS] Broadcast сообщение опубликовано в Redis: voice_channel_join
```

**Frontend консоль должна показать:**
```javascript
[WS] Получено сообщение: {type: 'voice_channel_join', ...}
```

## 📊 Схема работы

```
Пользователь A подключается к голосовому каналу
          ↓
Backend получает запрос join_voice
          ↓
Backend отправляет 2 типа уведомлений:
          ├─ В канал (только участники): "user_joined_voice"
          └─ ГЛОБАЛЬНО (все онлайн): "voice_channel_join"
          ↓
Redis broadcast передает на все инстансы
          ↓
Все пользователи получают уведомление через WebSocket
          ↓
Frontend обновляет UI:
   - Добавляет участника в список
   - Показывает аватарку с зеленой обводкой
   - Воспроизводит звук присоединения
```

## 🔍 Отладка

2. **Проверьте Redis:**
   ```bash

   ```

3. **Проверьте обработчики событий:**
   ```javascript

   ```

## 📝 Технические детали

### Типы WebSocket сообщений

**При входе в канал:**
```typescript
{
  type: 'voice_channel_join',
  user_id: number,
  username: string,
  voice_channel_id: number,
  voice_channel_name: string
}
```

**При выходе из канала:**
```typescript
{
  type: 'voice_channel_leave',
  user_id: number,
  username: string,
  voice_channel_id: number
}
```

### Redis каналы

- `user:{user_id}` - личные сообщения пользователю
- `channel:{channel_id}` - сообщения участникам конкретного канала
- `broadcast` - **НОВЫЙ** - глобальные сообщения всем онлайн пользователям
