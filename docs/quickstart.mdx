За несколько минут вы создадите приложение, установите бота и проверите его токен через REST API.

<Steps>
  <Step title="Откройте портал разработчика">
    Авторизуйтесь в Miscord и перейдите в [портал разработчика](https://miscord.ru/developers).
  </Step>
  <Step title="Создайте приложение">
    Нажмите **Создать**, задайте имя и описание. После создания Miscord покажет bot token и client secret один раз.
  </Step>
  <Step title="Сохраните токен">
    Поместите bot token в переменную окружения. Не добавляйте его в исходный код или публичный репозиторий.

    ```bash
    export MISCORD_BOT_TOKEN="ваш_токен"
    ```
  </Step>
  <Step title="Установите бота">
    В разделе **Бот** выберите необходимые разрешения, скопируйте ссылку установки и откройте её. Выберите сервер и подтвердите доступ.
  </Step>
  <Step title="Проверьте подключение">
    Выполните запрос к текущему пользователю бота:

    ```bash
    curl https://miscord.ru/api/v10/users/@me \
      -H "Authorization: Bot $MISCORD_BOT_TOKEN"
    ```

    При корректном токене API вернёт объект пользователя бота с HTTP `200`.
  </Step>
</Steps>

<Warning>
  Сброс токена немедленно отзывает предыдущий токен и отключает активные Gateway-сессии приложения.
</Warning>
